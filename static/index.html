GraphHacks Agent

Agent where the knowledge graph shapes what the agent does — built with FalkorDB.

📊 API Endpoints

GET / — This page
GET /api/status — Backend info & graph snapshot
POST /api/ask — Ask a question
POST /api/seed — Seed the graph
GET /api/memory/{user_id} — Memory summary
GET /docs — OpenAPI auto-docs

🚀 Ask a Question

curl -X POST http://localhost:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "Who has worked on the FalkorDB system?"}'

🔧 Project Structure

graph/          — GraphContext ABC + InMemory/FalkorDB backends
agent/           — GraphReasoner, AgentMemory, GraphExplainer
main.py          — CLI entry point
api.py           — FastAPI REST server
mcp_server.py    — MCP server (stdio mode)
